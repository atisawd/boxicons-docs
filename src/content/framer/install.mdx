# Framer Plugin

Access the complete Boxicons library directly within your Framer projects. Search, customize, and insert icons instantly.

## Installation

1. Open Framer.
2. Navigate to **Plugins** > **Browse Plugins**.
3. Search for "Boxicons".
4. Click **Install**.

<Callout type="info">
  Alternatively, visit the [Framer Plugin Store](https://www.framer.com/marketplace/plugins/boxicons-high-quality-web-icons/) to install directly.
</Callout>

## Usage

1. Open a project in Framer.
2. Launch the Boxicons plugin from the **Plugins** menu.
3. Browse or search for an icon.
4. Customize properties like color, size, and style in the plugin panel.
5. Click or drag an icon to insert it onto your canvas.

## Features

- **Extensive Library**: Access over 1,500 free icons and the full Pro collection.
- **Visual Customization**:
    - **Size**: Adjust from 16px to 512px.
    - **Color**: Set primary and secondary colors with opacity control.
    - **Transform**: Rotate and flip icons horizontally or vertically.
    - **Padding**: Toggle padding removal for precise alignment.
- **Smart Search**: Quickly find icons by name or keyword.
- **Favorites**: Save frequently used colors for consistency.

## Pro Features

Unlock the full potential of Boxicons with a Pro subscription:

- **All Icon Packs**: Access Duotone, Duotone Mix, and Duotone Solid packs.
- **Advanced Styles**: Use Rounded and Sharp corner styles.
- **Multiple Weights**: Choose from Thin, Normal, and Bold stroke weights.

### Activating Pro

1. Subscribe to a Pro plan at [boxicons.com/pricing](https://boxicons.com/pricing).
2. Retrieve your API token from your [Account Settings](https://boxicons.com/account/settings).
3. In the plugin, click the **Pro User?** link.
4. Paste your token and validate to unlock all features.
