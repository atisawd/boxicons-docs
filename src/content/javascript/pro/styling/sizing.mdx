# Sizing

### Size Presets

Use the `size` option for convenient preset sizes:

```javascript
import { createSvgString, Alarm } from '@boxicons-pro/js';

createSvgString(Alarm, { size: 'xs' });   // 16px
createSvgString(Alarm, { size: 'sm' });   // 20px
createSvgString(Alarm, { size: 'base' }); // 24px (default)
createSvgString(Alarm, { size: 'md' });   // 36px
createSvgString(Alarm, { size: 'lg' });   // 48px
createSvgString(Alarm, { size: 'xl' });   // 64px
createSvgString(Alarm, { size: '2xl' });  // 96px
createSvgString(Alarm, { size: '3xl' });  // 128px
createSvgString(Alarm, { size: '4xl' });  // 256px
createSvgString(Alarm, { size: '5xl' });  // 512px
```

### Custom Sizing

For custom sizes, use `width` and `height` options (overrides `size`):

```javascript
createSvgString(Alarm, { width: 32, height: 32 });
createSvgString(Alarm, { width: '48', height: '48' });
createSvgString(Alarm, { width: '2rem', height: '2rem' });
```
