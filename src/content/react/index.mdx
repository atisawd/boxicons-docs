# React Package

React icon library built from Boxicons SVG files with full tree-shaking support.
There are two versions available: Free and Pro.
Free version includes basic and filled icon packs (1 style & weight), while Pro unlocks all icon packs, styles, and weights. Both include brands pack.
They can be installed with two commands and used in the similar way.

The Icon Components are Tree-shakable, so only the icons you import will be included in your final bundle.
